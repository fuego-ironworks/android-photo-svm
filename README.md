# Android Photo SVM

Standalone, on-device photo segmentation and organic/inorganic region classification.

The repository owns a reusable C/Idriç computer-vision library and a small Android demonstration application. Browser integration is optional, not a prerequisite. Classification may be multilabel or unknown; no image is assumed to have an authoritative organic/inorganic label without evidence.

The initial implementation is being developed on a review branch. Android DEX/ICK integration and real-photo quality acceptance require separate verification.
